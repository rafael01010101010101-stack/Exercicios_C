# Exercícios em C

Repositório com exercícios desenvolvidos em **linguagem C**, com foco na prática de lógica de programação, funções, parâmetros e operações básicas.

## 📚 Exercícios

O programa possui um menu interativo com os seguintes exercícios:

| Nº | Exercício                                                      |
| -- | -------------------------------------------------------------- |
| 1  | Soma de dois números                                           |
| 2  | Subtração de dois números                                      |
| 3  | Média de três números                                          |
| 4  | Tabuada de um número                                           |
| 5  | Multiplicação de um número utilizando parâmetro                |
| 6  | Identificação do maior entre dois números utilizando parâmetro |
| 7  | Troca do posicionamento de dois números                        |

## 🧠 Conceitos praticados

* `printf` e `scanf`
* Variáveis e tipos de dados
* Operadores aritméticos
* Entrada e saída de dados
* Estruturas condicionais
* Funções
* Parâmetros
* Manipulação de valores
* Menu interativo
* Lógica de programação

## 🎯 Objetivo

Praticar os fundamentos da linguagem C e desenvolver a lógica de programação por meio de exercícios progressivos.
